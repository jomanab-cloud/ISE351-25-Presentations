Part 1: Machine Learning Foundations

The Machine Learning Landscape

Supervised Learning

  • Classification
    • Discrete outputs (categories)
    • Example: Penguin species
  • Regression
    • Continuous outputs (numbers)
    • Example: House prices

Unsupervised Learning

  • Clustering

The Universal ML Workflow

  1. Split data into training and testing sets
  2. Prepare features (scaling, encoding)
  3. Train model on training data
  4. Evaluate model on test data
  5. Iterate to improve performance

Emphasize that this workflow is consistent across all ML tasks, regardless of the specific algorithm being used.

Data Preparation Essentials

  • Train/Test Split: Why? To assess generalization
  • Feature Engineering: Creating meaningful predictors
  • Handling Missing Data: Imputation strategies
  • Scaling: Putting features on comparable scales
  • Categorical Encoding: Converting text to numbers

The quality of data preparation often determines model success more than algorithm choice.

Part 2: Classification with k-NN

k-Nearest Neighbors Concept

Core idea: Classify new observations based on the majority class of their k nearest neighbors.

Distance matters:

  • Euclidean: \(\sqrt{\sum(x_i - y_i)^2}\)

Choosing k: The Critical Parameter

Small k:

  • Focuses on local patterns
  • Low bias, high variance
  • Risk of overfitting

Large k:

  • Captures broader trends
  • High bias, low variance
  • Risk of underfitting

Rule of thumb: Start with \(k = \sqrt{n}\) where n is your training set size

Evaluating Classification Models

Confusion Matrix

             Predicted
             A   C   G
Actual  A   [43  2   0]
        C   [ 3 45   1]
        G   [ 0  0  36]

Metrics:

  • Accuracy = (43+45+36)/130 = 0.954
  • Precision (A) = 43/(43+3+0) = 0.935
  • Recall (A) = 43/(43+2+0) = 0.956

When to use what:
- Accuracy: Balanced classes
- Precision: Minimize false positives
- Recall: Minimize false negatives
- F1-Score: Balance precision & recall

Part 3: Linear Regression

The Intuition: From Averages to Lines

  1. Baseline: Predict the average price for all houses
  2. Better: Predict based on a single feature (square footage)
  3. Even Better: Add more relevant features (grade, waterfront)

Moving from simple averages to linear relationships dramatically improves predictions

Linear Regression Fundamentals

Simple Linear Regression: \[\text{Price} = \beta_1 \times \text{Sqft} + \beta_0\]

After fitting: \[\text{Price} = 240 \times \text{Sqft} + 52,509\]

Interpretation:
- Each additional square foot adds $240
- A hypothetical 0-sqft house costs $52,509

The line minimizes the sum of squared errors

Finding Optimal Parameters

Method 1: OLS Formula \[\beta_1 = \frac{N \times \sum(xy) - \sum x \times \sum y}{N \times \sum x^2 - (\sum x)^2}\]

\[\beta_0 = \frac{\sum y - \beta_1 \times \sum x}{N}\]

Method 2: Grid Search
- Try many combinations of \(\beta_0\) and \(\beta_1\)
- Calculate MSE for each combination
- Select parameters with lowest MSE

Works for any model, not just linear regression

Multiple Predictors: Multivariate Regression

Unfitted model: \[\text{Price} = \beta_1 \times \text{Sqft} + \beta_2 \times \text{Grade} + \beta_3 \times \text{Waterfront_yes} + \beta_0\]

Fitted model: \[\text{Price} = 240 \times \text{Sqft} + 45,000 \times \text{Grade} + 580,000 \times \text{Waterfront_yes} + 52,509\]

Interpretation:
- Each square foot adds $240
- Each grade point adds $45,000
- Being on the waterfront adds $580,000
- Base price is $52,509

Handling Categorical Variables

Problem:
- Models need numbers, not text
- “Yes” and “No” must become 1s and 0s

Bad Approach (One-Hot Encoding):
- Waterfront_yes = 1 or 0
- Waterfront_no = 1 or 0
- Creates redundancy (dummy trap)

Good Approach (Dummy Encoding):
- Waterfront_yes = 1 or 0
- (Waterfront_no is implied when yes = 0)

In tidymodels:

recipe(Price ~ ., data=train_data) %>%
  step_dummy(all_nominal_predictors())

Evaluating Regression Models

Common Metrics:
- MSE = \(\frac{1}{N} \sum(y_{pred} - y_{actual})^2\)
- RMSE = \(\sqrt{\text{MSE}}\) (in original units)
- MAE = \(\frac{1}{N} \sum |y_{pred} - y_{actual}|\)
- R?? = Proportion of variance explained

Example Results:
- RMSE: $226,564 (average error in dollars)
- R??: 0.582 (58.2% of price variation explained)

When to use what:
- RMSE: Sensitive to outliers
- MAE: More robust to outliers
- R-Squared: Interpretable scale (0-1)
- Adjusted R-Squared: Accounts for model complexity
